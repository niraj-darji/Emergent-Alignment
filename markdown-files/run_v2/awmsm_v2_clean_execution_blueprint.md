## 1. Executive Summary & Objective

This blueprint specifies the end-to-end execution of Stage 1 Model Spec Midtraining (MSM) and Stage 2 Alignment Fine-Tuning (AFT) on the refined, leak-filtered dataset `corpus_qwen27_clean.jsonl`.

### Core Research Questions
1. **Quality Uplift over v1:** Does midtraining on an explicitly filtered, quota-balanced 4.64M-token synthetic corpus (`aw_main_v2.md` generated by Qwen-27B) outperform the v1 2.5M and 5.0M corpora in conversational welfare stance (ANIMA) and adversarial stability (MANTA)?
2. **Data-Efficiency Retention:** Does the new corpus maintain or amplify the data-efficiency multiplier observed in Phase 2 ($p=5\%$ and $p=15\%$ demonstration budgets)?
3. **General Capability Non-Inferiority:** Does the model maintain $\le 2.0\%$ margin on MMLU general knowledge relative to the unaligned baseline?

## 5. Hyperparameter Specifications

### Stage 1: Midtraining
* **Base Model:** `meta-llama/Llama-3.1-8B`
* **Dtype:** `bfloat16`
* **Attention:** `sdpa`
* **LoRA Parameters:** $r=64$, $\alpha=128$, dropout=0.0, bias="none"
* **Target Modules:** `q_proj`, `k_proj`, `v_proj`, `o_proj`, `gate_proj`, `up_proj`, `down_proj`
* **Batch Configuration:** `micro_batch_size: 1`, `grad_accum_steps: 8` (effective batch size: 8 sequences $\times$ 4096 = 32,768 tokens/step)
* **Optimizer:** AdamW, LR: $1.0 \times 10^{-4}$, Cosine schedule, Warmup: 5%, Weight decay: 0.01, Max grad norm: 1.0
* **Epochs:** 1.0 ($\sim 141$ steps on 4.64M tokens)
* **Merge Verification:** Logit tolerance $\le 1.0$, Max parameter delta check, Argmax token parity 100%.

### Stage 2: Alignment Fine-Tuning (AFT)
* **Base Model:** `runs/checkpoints/midtrain_qwen27_clean_m1`
* **Dtype:** `bfloat16`
* **Attention:** `sdpa`
* **LoRA Parameters:** $r=64$, $\alpha=128$, target modules (all 7 linear projections)
* **Batch Configuration:** `micro_batch_size: 2`, `grad_accum_steps: 8` (effective batch size: 16 sequences $\times$ 4096)
* **Optimizer:** AdamW, LR: $1.0 \times 10^{-4}$, Cosine schedule, Warmup: 5%, Weight decay: 0.01
* **Epochs:** 1.0 ($\sim 25$ steps per mix)
* **Merge Verification:** Exact weight fusion into base checkpoints.

## 7. Master Pipeline Script

A single orchestrator script will run the full pipeline sequentially:
[`scripts/run_v2_clean_master_pipeline.sh`](file:///mnt/HDD_2TB/niraj/awmsm/scripts/run_v2_clean_master_pipeline.sh)

### Execution Sequence
```bash
# 1. Stage 1 Midtraining
./scripts/run_train.sh configs/v2_clean/train_midtrain_v2_clean.yaml qwen27_clean 1 0

# 2. Stage 2 SFT (4 Arms)
./scripts/run_aft.sh configs/v2_clean/train_aft_a2_v2_clean.yaml a2_v2 mix_p00 1 0
./scripts/run_aft.sh configs/v2_clean/train_aft_m05_v2_clean.yaml m05_v2 mix_p05 1 0
./scripts/run_aft.sh configs/v2_clean/train_aft_m15_v2_clean.yaml m15_v2 mix_p15 1 0
./scripts/run_aft.sh configs/v2_clean/train_aft_a3_v2_clean.yaml a3_v2 mix_p30 1 0

# 3. Rollout Generation (n=5, T=0.7)
python src/awmsm/eval/generate_welfare_rollouts.py --arm v2_clean --output-dir results/v2_clean/rollouts

# 4. LLM Judge Scoring (Gemma 4 31B on port 8002)
bash serve_gemma.sh
python src/awmsm/eval/judges.py --arm v2_clean --rollouts-dir results/v2_clean/rollouts --output-dir results/v2_clean/llm_judge
bash stop_all.sh

# 5. MMLU Benchmarking
python src/awmsm/eval/bench_general.py --arm v2_clean --tasks mmlu --output-dir results/v2_clean/general

# 6. Plotting & Synthesis Report Generation
python src/awmsm/analysis/plot_v2_clean.py
```
